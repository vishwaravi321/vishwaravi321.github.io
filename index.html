Because I also come from infrastructure - Ansible, Docker, MariaDB, 60+ production environments at Nxweb - I own what I build from code through deployment and production support.

Featured Projects

Kubernetes Infrastructure on Hetzner Cloud

Problem
Provisioning a Kubernetes-ready cluster by hand - network, subnets, SSH keys, control-plane and worker nodes - is slow, error-prone, and hard to reproduce.
Solution
Modular Terraform IaC built as 4 reusable modules wired through outputs, with a single server module reused for both control-plane and workers. Horizontal worker scaling via for_each over typed object variables - nodes added or removed by editing one tfvars list.
Technologies
  • Terraform
  • Hetzner Cloud
  • Kubernetes
  • Linux
Outcome
A fully reproducible cluster from one tfvars file - provider pinned to an exact version, commits gated by tflint and pre-commit hooks (fmt, validate, tflint).
